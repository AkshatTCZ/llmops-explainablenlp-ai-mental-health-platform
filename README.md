# AI Mental Health Platform

## Features
- Emotion Detection (GoEmotions)
- Explainable AI (SHAP)
- Chatbot (LLM)
- Exercise Recommendations
- Book Recommendations (Google Books API)

## Tech Stack
- FastAPI
- Node.js frontend
- HuggingFace Transformers
- Ollama / LLM
- AWS (planned)

## Setup
1. Clone repo
2. Add .env file
3. Run backend:
   uvicorn app.main:app --reload
